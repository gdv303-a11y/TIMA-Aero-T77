# TIMA Aero T77

Независимый открытый проект по 3D-моделированию и исследованию аэродинамики FAW Bestune T77. Первая задача — проверить, какие зоны кузова могут быть связаны с шумом на трассе. Начнём с наружных зеркал, передних стоек и верхней кромки лобового стекла.

## С чего начать

1. Описать геометрию исходной модели и отметить упрощения.
2. Подготовить базовый расчёт обтекания и проверить его чувствительность к размеру сетки.
3. Сравнить варианты геометрии в одинаковых условиях и сопоставить гипотезы с измерениями.

Сейчас проект на этапе подготовки. Подтверждённых результатов расчётов и измерений пока нет.
