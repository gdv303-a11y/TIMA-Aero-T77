# План исследования

1. Подготовить приближённую базовую геометрию кузова. Отдельно описать наружные зеркала, передние стойки и верхнюю кромку лобового стекла.
2. Рассчитать базовое обтекание и проверить чувствительность выводов к сетке и упрощениям геометрии.
3. Менять по одному элементу и сравнивать поля давления и скорости при одинаковых условиях.
4. Сопоставить гипотезы с повторяемыми измерениями. При записи фиксировать условия, положение микрофона и настройки аппаратуры.

В отчёте отделяй данные измерений от результатов моделирования. Для каждого сравнения указывай версии геометрии, параметры расчёта и ограничения применимости выводов.
