# Расчёты обтекания

Для каждого случая указывай версию геометрии, решатель, размер расчётной области, параметры сетки, скорость и угол набегающего потока, граничные условия и критерии сходимости. Фиксируй допущения о движении земли и вращении колёс.

Сравнивай геометрические варианты при одинаковых настройках. Записывай результаты проверки чувствительности к сетке и сохраняй команды запуска. Поля давления и скорости помогают формулировать акустические гипотезы. Для оценки шума в салоне нужны акустические измерения.
