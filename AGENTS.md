# Работа с TIMA Aero T77

- Перед изменениями прочитай корневой README и документацию каталога, с которым работаешь.
- Добавляй только материалы с подтверждёнными правами на публичное размещение. Для каждого внешнего материала запиши источник, автора и условия использования. Держи черновики и материалы с неясным происхождением вне Git.
- Для геометрии указывай единицы, направления осей, версию исходных данных и допущения. Для CFD фиксируй версию геометрии, решателя, сетку, граничные условия и критерии сходимости.
- Разделяй гипотезы, расчётные оценки и измерения. Выводы о шуме в салоне требуют акустических данных.
- Для изменений документации проверь локальные ссылки. Для изменений моделей и расчётов выполни доступные проверки из соответствующего README. В отчёте укажи, что удалось проверить.
