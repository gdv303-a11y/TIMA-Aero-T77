# Геометрия и CAD

Храни здесь проверенные исходники моделей и инструкции по их экспорту. Для каждой версии модели указывай её назначение, единицы, ориентацию осей, происхождение размеров и допущения. Помечай приблизительные поверхности и участки с неизвестными размерами.

Перед передачей геометрии в CFD проверь масштаб, ориентацию, замкнутость тела и отсутствие самопересечений. Для параметрической модели укажи инструмент, его версию и порядок экспорта.
